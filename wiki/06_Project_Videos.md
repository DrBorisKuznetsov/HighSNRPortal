# Подпроект: YouTube Catalog (Каталог Видео)

Раздел Videos (`videos_project`) выделен в **абсолютно независимый подпроект** со своим циклом сборки и репозиторием.

## Архитектура
- **Технологии:** React + Vite.
- **Интеграция с главным порталом:** Главный портал ссылается на этот проект через стандартную HTML-ссылку (переход между проектами). Локально ссылка ведет на `http://localhost:5174/videos_project/`, в продакшене - на `/videos_project/`.
- **Внешний вид:** Использует общие стилевые решения (светлые пастельные тона, премиальный дизайн без шума) из `portal/src/index.css`.

## Логика данных
- Проект содержит скрипт синхронизации `scripts/fetch-videos.ts`, который работает с YouTube Data API v3.
- Данные (статистика канала, видео, плейлисты) генерируются в статические JSON-файлы в папке `src/data/`.
- Обновление каталога происходит независимо от обновления главного портала (локально через `npm run sync-youtube` или автоматически через CI/CD GitHub Actions).

## Структура интерфейса
- **Header:** Ссылка "Back to Portal" для возврата на главный портал.
- **Channel Stats:** Блок со статистикой канала (подписчики, просмотры, видео) с логотипом канала.
- **Video Grid:** Сетка видеокарточек с эстетичным отображением метаданных.

## Стабилизационные правки 2026-06-29

- Production build больше не падает на неиспользуемом импорте `React`.
- Путь к `channel-logo.png` строится через `import.meta.env.BASE_URL`, чтобы корректно работать с `base: '/videos_project/'`.
