# Подпроект: Open Projects (Hardware & Software)

Раздел Open Projects (Открытые проекты) предназначен для публикации реальных аппаратных и программных разработок лаборатории (отладочные платы, измерительные установки, библиотеки).

## Структура раздела

`/projects` должен оставаться плоским реестром реальных hardware/software/measurement проектов. В этот раздел не добавляются другие разделы портала вроде `Tools`, `Education Tools`, `Courses` или `Research`.

Все проекты физически хранятся в своих собственных GitHub-репозиториях или независимых рабочих папках (код, схемы, герберы, измерительные данные). Портал служит **витриной** и точкой входа в эти проекты.

**Структура URL на портале:**
```text
/projects
/projects/project-slug   # только если проекту нужна отдельная подробная страница
```

Пока проектов немного, отдельные вложенные страницы не обязательны. Достаточно компактного списка на `/projects` со статусом, краткой сутью и одной-двумя ссылками.

## Карточка и Страница Проекта

Для каждого проекта на портале создается Markdown-страница со следующим содержимым:
- Название проекта.
- Краткое описание инженерной задачи.
- **Статус проекта:** 
  - `concept` (идея/исследование)
  - `prototype` (в разработке)
  - `validated` (проверено, работает)
  - `archived` (устарело)
- Фотографии или рендеры платы/стенда.
- Схемотехника (вставка изображений или PDF-схем).
- Спецификации:
  - Ссылка на BOM (перечень элементов).
  - Ссылка на PCB (файлы для производства).
  - Ссылка на Firmware / FPGA code (если применимо).
- Инструкции "Как повторить проект".
- Ссылка на основной репозиторий **GitHub**.

## Интеграция с GitHub

Проекты очень тесно связаны с GitHub. Каждая страница проекта должна явно вести на репозиторий, который в свою очередь содержит:
- `README.md` (базовое описание).
- `Issue tracker` (для сбора обратной связи и проблем от комьюнити).
- `Release notes` (версии плат или софта).
- `License` (открытая лицензия, например MIT или CERN OHL).

**Принцип:** Портал описывает *почему* мы это сделали и *как* это работает теоретически (Research), а GitHub содержит материалы для того, чтобы *сделать* это руками.
