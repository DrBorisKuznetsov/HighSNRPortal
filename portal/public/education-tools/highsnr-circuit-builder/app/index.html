About HighSNR Circuit Builder

HighSNR Circuit Builder is an intuitive web-based tool designed to easily sketch electronic schematics and shapes, and seamlessly export them to Manim Python scripts.

It allows for rapid prototyping of visual circuits which can be directly animated using the provided circuit_lib.py library.

Hotkeys & Controls

Left Click Place component, or Select/Drag in Pointer mode.
Right Click Rotate selected component. In Corner mode, flip corner direction.
Mid-Click / Shift+Drag Pan the canvas.
Mouse Wheel Zoom in / Zoom out.
Delete / Backspace Delete the currently selected component.
Ctrl + Z Undo the last placed component.
Escape Switch back to Pointer tool and deselect.
Double Click Double click on a text label to edit its content.
